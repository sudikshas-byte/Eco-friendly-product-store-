# 🌿 EcoStore — Eco-Friendly E-Commerce Website

### 🌎 Shop Sustainably. Live Responsibly.

EcoStore is my first frontend web development project, built using **HTML, CSS, and JavaScript**. It is a responsive, interactive e-commerce website designed to promote sustainable shopping and environmentally friendly products.

The project combines modern UI design, smooth animations, and interactive shopping features to create an engaging user experience.

---

## 🚀 Features

- 🌱 **Eco-Friendly Product Catalog** — Explore 40+ sustainable products, including reusable bags, bamboo products, and biodegradable essentials.
- 🛒 **Shopping Cart** — Add products to a cart and view selected items.
- ❤️ **Wishlist** — Mark your favourite products.
- 🌙 **Dark/Light Mode** — Switch between different website themes.
- ✨ **Animated Homepage** — Dynamic background slideshows, neon effects, and typing animations.
- 👀 **Quick Product View** — Preview product details without leaving the page.
- 📱 **Responsive Design** — Layouts adapted for desktop, tablet, and mobile screens.
- 💬 **Customer Testimonials** — Display customer feedback.
- 📩 **Contact Form** — Frontend form with basic input validation.
- 📧 **Newsletter Section** — Email subscription interface with basic validation.

## ⚙️ How It Works

1. Users visit the EcoStore homepage.
2. The homepage displays animated visuals and sustainability messages.
3. Users browse the eco-friendly product collection.
4. Products can be viewed, added to the cart, or saved to a wishlist.
5. Users can switch between dark and light themes.
6. Contact and newsletter forms provide basic frontend validation.

---

## ⚠️ Current Limitations

EcoStore is currently a **frontend-only demonstration project**.

- Checkout is a placeholder; payment processing is not implemented.
- Shopping cart and wishlist data are maintained in browser memory.
- Contact form submissions and newsletter subscriptions are not connected to a backend.
- Product details are stored directly in JavaScript.
